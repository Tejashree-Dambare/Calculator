# Calculator

A responsive and user-friendly Calculator web application built using **HTML, CSS, and JavaScript**. The application allows users to perform basic arithmetic operations with a clean, modern, and responsive interface.

## 🚀 Features

- Addition, subtraction, multiplication, and division
- Percentage calculation
- Decimal number support
- Clear all calculations using the AC button
- Delete the last entered value
- Keyboard support for calculations
- Display previous calculation
- Responsive and mobile-friendly design
- Modern glassmorphism user interface
- Smooth button hover and click effects
- Simple and easy-to-use interface

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layout, responsive design, and animations
- **JavaScript** – Calculator logic and interactive functionality
- **DOM Manipulation** – Updating calculator display and handling user input

## 📌 How It Works

Users can enter numbers and operators using the calculator buttons or their keyboard.

The calculator supports:

- Addition using the **+** operator
- Subtraction using the **−** operator
- Multiplication using the **×** operator
- Division using the **÷** operator
- Percentage using the **%** operator
- Decimal calculations using the **.** button
- Deleting the last entered value using the **⌫** button
- Clearing the complete calculation using the **AC** button
- Calculating the result using the **=** button

The application uses **JavaScript** to process the entered expression and display the calculated result.
